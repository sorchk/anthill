# Anthill - 快速开始指南

**5分钟快速上手**

---

## 1. 使用Docker启动

```bash
# 克隆或下载
cd anthill-admin

# 启动服务
docker compose up -d

# 等待10秒
sleep 10

# 查看状态
docker compose ps
```

## 2. 访问管理面板

打开: http://localhost:3008

登录: `admin` / `admin123`

## 3. 部署运行时节点

在您想要管理的任何机器上:

```bash
# 下载适合您平台的anthill-runtime
# 运行
./anthill-runtime -admin wss://your-admin-host:8080/ws
```

节点将自动注册到管理面板。

## 4. 上传插件

1. 管理面板 → 插件
2. 点击"上传插件"
3. 选择一个`.wasm`文件
4. 填写名称、版本、类型
5. 点击上传

## 5. 部署插件到节点

1. 节点 → 选择您的节点
2. 点击"插件"标签
3. 点击"安装插件"
4. 从仓库选择插件
5. 点击安装

## 6. 执行插件

1. 节点 → 选择您的节点
2. 点击"执行"
3. 选择插件和方法
4. 查看结果
