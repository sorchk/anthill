# Anthill 国际化 (i18n) 设计方案

**日期:** 2026-05-02
**状态:** 已批准

## 1. 概述

为 Anthill 管理平台添加国际化支持，实现中文/英文双语切换。

## 2. 技术方案

### 技术选型

- **vue-i18n**: Vue 3 官方国际化方案
- **Pinia**: 状态管理（已有）

### 语言检测逻辑

```
用户设置 (localStorage) → 浏览器 Accept-Language → 默认中文
```

## 3. 目录结构

```
src/
├── locales/
│   ├── index.ts          # i18n 初始化
│   ├── zh-CN.json         # 中文翻译
│   └── en-US.json         # 英文翻译
├── stores/
│   ├── auth.ts           # 现有认证store
│   └── locale.ts         # 新增：语言状态管理
```

## 4. UI 设计

### 语言选择器位置

在 Layout.vue 导航栏右上角添加语言下拉菜单。

### 交互流程

1. 点击语言图标显示下拉菜单
2. 选择语言后立即切换，无需刷新
3. 用户选择保存到 localStorage

## 5. 翻译范围

- 导航菜单
