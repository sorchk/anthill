## 1. 项目概述

Anthill 是一个全面的 TCP 协议远程管理平台，支持 WASM 插件热插拔、端到端加密通信、流量混淆和多平台部署。

### 1.1 系统架构

│  │ (Vue3+Naive)│  │  (桌面客户端) │  │  (Go+Gin)   │         │

│         │                 │                 │               │

### 1.2 核心组件

| 组件 | 技术栈 | 描述 |
|------|--------|------|
| `admin/` | Go + Gin + SQLite | 管理后台 API 服务 |
| `web/` | Vue3 + NaiveUI | Web 管理界面 |
| `runtime/` | Go + wazero | 运行时节点代理 |
| `client/` | Tauri + Vue3 | 桌面客户端 |

## 3. 环境配置与依赖

### 3.1 前置要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Go | ≥ 1.25 | 后端运行时 |
| Node.js | ≥ 18 | 前端构建 |
| npm/pnpm | 最新版 | 包管理 |
| Git | 任意版本 | 版本控制 |
| SQLite | 3.x | 数据库（已内嵌） |
| air | 最新版 | Go 热重载工具 |

### 3.2 安装 air（Go 热重载）

```bash
# 安装 air
go install github.com/air-verse/air@latest

# 确认安装成功
air --version
```

### 3.3 环境变量

#### Admin 服务

| 变量 | 默认值 | 描述 |
|------|--------|------|
| `ADMIN_PORT` | `8080` | 服务端口 |
| `ADMIN_DB_PATH` | `./data/admin.db` | 数据库路径 |
| `ADMIN_JWT_SECRET` | - | JWT 密钥（必填） |
| `ADMIN_ADMIN_EMAIL` | `admin` | 初始管理员邮箱 |
| `ADMIN_ADMIN_PASSWORD` | `admin123` | 初始管理员密码 |

#### Runtime 节点

| 变量 | 默认值 | 描述 |
|------|--------|------|
| `RUNTIME_PORT` | `18888` | 监听端口 |
| `RUNTIME_ADMIN_URL` | - | Admin 服务地址（必填） |
| `RUNTIME_PLUGIN_DIR` | `./plugins` | 插件目录 |
| `RUNTIME_LOG_LEVEL` | `info` | 日志级别 |

### 3.4 快速安装

```bash
# 克隆项目
git clone <repository>
cd anthill

# 安装前端依赖
cd web && npm install && cd ..

# 安装后端依赖
cd admin && go mod download && cd ..
cd runtime && go mod download && cd ..

# 安装 air（Go 热重载工具）
go install github.com/air-verse/air@latest

# 构建所有组件
make build
```

## 4. 开发运行

### 4.1 启动后端（Go + air 热重载）

在 `admin/` 目录下使用 air 启动：

```bash
cd admin
air
```

air 会自动读取项目根目录下的 `air.toml` 配置文件，实现：
- 代码修改后自动编译重启
- 保留运行状态
- 彩色日志输出

### 4.2 启动前端（Vite 开发服务器）

在 `web/` 目录下启动：

```bash
cd web
npm run dev
```

前端默认运行在 `http://localhost:3000`，会自动代理 API 请求到后端服务。

### 4.3 同时启动前后端

推荐在两个终端分别运行：

```bash
make dev
```

### 4.4 访问地址

| 服务 | 地址 |
|------|------|
| 前端界面 | http://localhost:3000 |
| 后端 API | http://localhost:8080 |
| API 基础路径 | http://localhost:8080/api |
